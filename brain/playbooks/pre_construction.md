Work through this before the first trade arrives.[^beam_precon] Approval
and insurance names follow NSW usage (development consent or CDC,
construction certificate, BASIX, home building compensation). Other states
use different names for the same steps: see the [state rules](/states/overview.md).

## Contracts & Approvals

- [ ] Building contract signed by all parties
- [ ] Development consent / CDC obtained
- [ ] Construction certificate issued
- [ ] Home building compensation insurance in place
- [ ] Deposit received
- [ ] Builder licence current and valid
- [ ] Public liability insurance current
- [ ] Workers compensation insurance current

## Design & Documentation

- [ ] Approved plans on site
- [ ] Engineering drawings received and reviewed
- [ ] Specifications complete and issued
- [ ] Soil / geotechnical report obtained
- [ ] Survey plan obtained (boundaries, levels, setbacks)
- [ ] Energy rating / BASIX certificate obtained
- [ ] Bushfire assessment (if applicable)
- [ ] Flood report (if applicable)

## Site Preparation

- [ ] Site inspection completed
- [ ] Before You Dig Australia (BYDA) enquiry completed
- [ ] Service locations marked on site
- [ ] Tree protection measures in place (if applicable)
- [ ] Sediment and erosion controls installed
- [ ] Temporary fencing / hoarding installed
- [ ] Site toilet ordered and delivered
- [ ] Skip bin / waste management arranged
- [ ] Temporary power connected or generator on site
- [ ] Temporary water connected
- [ ] Site sign installed (as per council requirements)

## Safety & Compliance

- [ ] Site safety management plan prepared
- [ ] First aid kit on site
- [ ] Fire extinguisher on site
- [ ] Emergency contact list displayed
- [ ] WHS notification to SafeWork (if required)
- [ ] Asbestos inspection / report (demolition)
- [ ] SWMS prepared for initial high-risk work

## Neighbours & Access

- [ ] Adjoining owners notified
- [ ] Party wall agreements (if applicable)
- [ ] Site access confirmed (driveways, crane access)
- [ ] Council road / footpath permits (if required)
- [ ] Parking arrangements confirmed

## Trades & Program

- [ ] Construction program prepared
- [ ] Key trades booked with start dates confirmed
- [ ] Long-lead items identified and ordered
- [ ] Client selections required before lock-up identified
