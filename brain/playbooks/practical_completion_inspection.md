Walk the job with this list before issuing the
[Practical Completion Notice](/documents/practical_completion_notice.md).[^beam_pc_checklist]
Anything not done becomes a line in the
[Defects List](/documents/defects_list_tracking.md), with a trade and a
priority. Skip "if in scope" items that aren't in the contract.

Certificates are part of PC: have the waterproofing, electrical, plumbing
and gas certificates in hand, and the occupation certificate where the
state requires one, before telling the client the works are complete
([handover documents](/documents/as_built_documentation_register.md)).

## External: Site

- [ ] Driveway and paths complete, clean, no damage
- [ ] Landscaping complete per contract/plans
- [ ] Retaining walls complete and drainage functional
- [ ] Fencing complete (if in scope)
- [ ] Letterbox installed (if in scope)
- [ ] Clothesline installed (if in scope)
- [ ] External taps functional
- [ ] Stormwater connected and draining correctly
- [ ] Site clean — all builder rubbish removed
- [ ] Temporary fencing removed

## External: Building

- [ ] Brickwork / cladding — clean, no damage, weep holes clear
- [ ] Roof — tiles/sheeting secure, no visible defects
- [ ] Gutters and downpipes — secure, no leaks, connected
- [ ] Fascia and eaves — painted, no gaps or damage
- [ ] Windows — clean, operational, hardware functional, no scratches
- [ ] External doors — operational, locks work, weather seals intact
- [ ] External painting — complete, even coverage, no runs or misses
- [ ] Meter boxes — labelled, accessible

## Internal: General (Each Room)

- [ ] Walls — plaster smooth, no cracks, nail pops, or marks
- [ ] Ceilings — smooth, level, no marks or damage
- [ ] Cornices — straight, neat joins, no gaps
- [ ] Painting — even coverage, clean edges, no drips or patches
- [ ] Doors — open/close smoothly, latches work, no damage
- [ ] Door furniture — handles, locks, stops all installed and working
- [ ] Windows — open/close smoothly, locks work, clean, no scratches
- [ ] Skirting boards — straight, neat joins, no gaps, painted
- [ ] Architraves — neat, mitre joints tight, painted
- [ ] Power points and light switches — functional, straight, covers flush
- [ ] Light fittings — installed, working, correct type
- [ ] Floor — clean, level, no damage, correct finish

## Kitchen

- [ ] Benchtop — no chips, scratches, or marks
- [ ] Cabinetry — doors and drawers aligned, soft-close works
- [ ] Splashback — installed, neat, sealed correctly
- [ ] Sink and taps — functional, no leaks, drains freely
- [ ] Appliances — installed, connected, functional (if in scope)
- [ ] Rangehood — installed, vented, functional
- [ ] Pantry — shelving installed as per plan

## Bathrooms / Ensuite / WC

- [ ] Tiling — grout complete, no chips or cracks, falls to drain
- [ ] Shower screen — installed, sealed, no leaks
- [ ] Vanity — installed level, doors aligned, no damage
- [ ] Toilet — secure, flushes correctly, no leaks
- [ ] Taps and mixers — functional, correct temperature
- [ ] Drains — all draining freely
- [ ] Mirrors — installed (if in scope)
- [ ] Towel rails and accessories — installed securely
- [ ] Exhaust fan — functional, vented to exterior
- [ ] Waterproof membrane — certificate obtained

## Laundry

- [ ] Tub / sink installed and functional
- [ ] Taps — functional, no leaks
- [ ] Cabinetry — installed per plan
- [ ] Washing machine taps — accessible, functional
- [ ] Dryer vent — installed (if applicable)
- [ ] Floor waste — draining correctly

## Garage

- [ ] Garage door — operational, remote working
- [ ] Floor — finished, no major cracks
- [ ] Walls and ceiling — lined / finished per plan
- [ ] Power points and lighting — functional
- [ ] Vehicle clearance — adequate

## Services & Compliance

- [ ] Smoke alarms — installed, tested, compliant
- [ ] Electrical compliance certificate obtained
- [ ] Plumbing compliance certificate obtained
- [ ] Gas compliance certificate (if applicable)
- [ ] Air conditioning — installed, functional (if in scope)
- [ ] Hot water system — installed, functional
- [ ] TV / data points — functional
- [ ] NBN / communications — connected (if in scope)
