A hold point is a check that must pass before work continues, usually
because the next step covers it up.[^beam_hold_points] Record each sign-off
(date and who) in the [site diary](/documents/site_diary.md), and keep the
certificates for the [claim support pack](/playbooks/claim_support_pack.md)
and for handover. The certifier's mandatory inspection stages come from the
approval conditions; see each [construction phase](/phases/index.md).

## Foundations & Slab

| Hold point | Checked by | Done |
|---|---|---|
| Set-out check (boundaries, levels, setbacks) | Surveyor | ☐ |
| Excavation / pier holes — depth, size, soil conditions | Engineer / Builder | ☐ |
| Reinforcement — size, spacing, cover, tie wire, chairs | Engineer / PCA | ☐ |
| Plumbing rough-in under slab | Plumber / Hydraulic | ☐ |
| Termite treatment / barrier installed | Pest company | ☐ |
| Vapour barrier / membrane installed correctly | Builder | ☐ |
| Pre-pour inspection (PCA mandatory hold point) | PCA / Certifier | ☐ |

## Frame Stage

| Hold point | Checked by | Done |
|---|---|---|
| Frame erected to approved plans | Builder / Carpenter | ☐ |
| Bracing installed per engineer's details | Builder | ☐ |
| Tie-down / cyclone connections (if applicable) | Builder | ☐ |
| Window and door openings checked against schedule | Builder | ☐ |
| Frame inspection (PCA mandatory hold point) | PCA / Certifier | ☐ |
| Wet area frame waterproofing prep | Builder | ☐ |

## Pre-Lining / Lock-Up

| Hold point | Checked by | Done |
|---|---|---|
| Roof covering complete and weatherproof | Roofer / Builder | ☐ |
| Sarking / roof blanket installed | Builder | ☐ |
| Windows and external doors installed | Builder | ☐ |
| Plumbing rough-in (top-out) complete | Plumber | ☐ |
| Electrical rough-in complete | Electrician | ☐ |
| Insulation installed to NCC requirements Insulation / | Builder | ☐ |
| Waterproofing to wet areas (PCA hold point) | PCA / Certifier | ☐ |
| Pre-lining / pre-plaster inspection | PCA / Certifier | ☐ |

## Fixing & Fit-Off

| Hold point | Checked by | Done |
|---|---|---|
| Plasterboard fixed, joints and cornices complete | Plasterer | ☐ |
| Joinery and cabinetry installed to plan | Joiner | ☐ |
| Tiling complete — falls, grout, waterproof integrity | Tiler | ☐ |
| Painting complete — prep, coats, finish quality | Painter | ☐ |
| Plumbing fit-off — taps, toilets, hot water | Plumber | ☐ |
| Electrical fit-off — GPOs, lights, switches, smoke alarms | Electrician | ☐ |
| Flooring installed and protected | Floor layer | ☐ |

## Practical Completion

| Hold point | Checked by | Done |
|---|---|---|
| Final clean complete | Cleaner / Builder | ☐ |
| All defects rectified from internal inspection | Builder | ☐ |
| Smoke alarms tested and compliant | Electrician | ☐ |
| Final plumbing compliance certificate | Plumber | ☐ |
| Final electrical compliance certificate | Electrician | ☐ |
| Occupation certificate issued | PCA / Certifier | ☐ |
| Client handover inspection completed | Builder / Client | ☐ |
