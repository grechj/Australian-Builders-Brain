Send this with every [progress claim](/contracts/progress_payments.md),
as a single PDF or a clearly labelled folder.[^beam_claim_pack] A
well-documented claim gets paid faster and is harder to dispute.

## Core Claim Documents

- [ ] Progress claim invoice (tax invoice with ABN)
- [ ] Cover letter / claim summary
- [ ] Updated progress schedule / program
- [ ] Statutory declaration (if required by contract)

## Evidence Of Work Completed

- [ ] Progress photos (dated, showing work completed)
- [ ] Site diary extracts for claim period
- [ ] Inspection certificates / hold point sign-offs
- [ ] Survey / set-out confirmation (slab stage)
- [ ] Frame inspection certificate (frame stage)

## Variation Documentation

- [ ] Approved variation orders (signed by client)
- [ ] Updated variation register
- [ ] Supporting quotes / invoices for variation costs

## Subcontractor Documentation

- [ ] Subcontractor invoices / payment claims
- [ ] Statutory declarations from subcontractors (if required)
- [ ] Workers compensation certificates (current)

## Insurance & Compliance

- [ ] Home building compensation certificate (current)
- [ ] Public liability certificate of currency
- [ ] Workers compensation certificate of currency

## Extension Of Time (If Applicable)

- [ ] EOT notification letter(s)
- [ ] Weather records / BOM data
- [ ] Delay cause documentation
- [ ] Updated program showing impact
