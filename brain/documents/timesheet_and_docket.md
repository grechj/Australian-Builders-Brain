# Structure

Use this outline to produce the document in any format (your own letterhead, an email, a PDF). To fill the template itself, use `tools/fill_template.py`.

**Sheet: Setup**

- Fields: Business Name, Project Name, Project Address, Client Name, Contract Number, Default Labour Rate (excl GST)

**Sheet: Dockets**

- One row per entry from row 5. Columns to enter: Date, Docket No, Worker, Trade / Role, Start, Finish, Break (min), Materials / Plant (excl GST), Work Done, Charge To (Contract / VAR No), Signed Off By
- Calculated columns: Hours, Rate (excl GST), Labour (excl GST), Total (excl GST)

**Sheet: Summary**

- One row per entry from row 4. Columns to enter: Charge To
- Calculated columns: Hours, Labour (excl GST), Materials / Plant (excl GST), Total (excl GST), GST, Total (incl GST)
- Pre-set rows: All dockets

**Sheet: Instructions**: how to use the workbook
