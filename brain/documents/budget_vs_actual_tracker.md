# Structure

Use this outline to produce the document in any format (your own letterhead, an email, a PDF). To fill the template itself, use `tools/fill_template.py`.

**Sheet: Setup**

- Fields: Business Name, ABN, Builder Licence, Address, Phone, Email, Project Name, Project Address, Client Name, Client Phone, Client Email, Contract Number, Contract Sum (incl GST)

**Sheet: Budget vs Actual**

- One row per entry from row 5. Columns to enter: Trade/Item, Budget ($), Committed ($), Spent ($), Status, Notes, Variance = budget less committed (or spent, if higher). Negative = forecast overrun.
- Calculated columns: Remaining ($), Variance ($), % Used
- Pre-set rows: Preliminaries, Demolition, Excavation, Concrete, Framing, Roofing, Brickwork/Cladding, Windows/Doors, Plumbing, Electrical, Insulation, Plasterboard, Tiling, Joinery, Painting, Flooring, Landscaping, Contingency, Other, TOTAL
- Dropdown values: H5:H23: On Track,At Risk,Over Budget,Complete
